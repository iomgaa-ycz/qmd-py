# Inbox（碎片收件箱）

这里放“还没想清楚 / 还没决定归档到哪里 / 只是先抓住不想丢”的内容。

## 你写入 Inbox 的原则（低摩擦）

- 允许很短、很碎、很随手。
- **不要求**当场补全标签、双向链接、完整结构。
- **要求**：不要用 Untitled；至少写一句“这条在说什么”。

## 婷婷（AI）如何维护 Inbox（提纯流程）

建议频率：每周一次（或积累到 20 条再处理）。

提纯时我会：
1. 给碎片补一个清晰标题（必要时重命名文件）
2. 判断归属：
   - 进入某个 `Area/`（领域 MOC）
   - 或进入某个 `Projects/`（项目）
   - 或沉淀为 `note/` 下的可复用知识卡片
3. 补最小元数据：`tags: [inbox, ...]`（必要时加领域/项目标签）
4. 如适合，会把内容“升格”为结构化笔记（带小标题/结论/引用）

## 清空策略

- Inbox 不追求永久保存：被提纯后即可移动出 Inbox。
- 未提纯但长期不再关心的碎片，可合并到一篇“冷冻箱”笔记里再归档。
