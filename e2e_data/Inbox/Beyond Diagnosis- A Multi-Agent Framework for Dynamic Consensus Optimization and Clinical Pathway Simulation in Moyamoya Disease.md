## 1.研究背景
### 1.1 烟雾病临床决策的复杂性与多学科挑战

烟雾病（Moyamoya Disease, MMD）是一种罕见的慢性进行性脑血管闭塞性疾病，主要特征为颈内动脉末端狭窄及颅底异常血管网的形成。尽管血管重建手术（如直接搭桥、间接搭桥或联合搭桥）是目前预防卒中和改善认知功能的标准治疗手段，但其围术期管理极具挑战性。临床决策往往需要在改善脑灌注与预防术后脑高灌注综合征（CHS）之间寻求微妙的平衡，后者可能导致严重的神经功能恶化甚至出血。因此，MMD的诊疗高度依赖多学科团队（MDT）的协作，涉及神经外科、神经内科、放射科及重症监护专家的共同参与，以综合评估血管解剖、血流动力学及患者的认知储备。

### 1.2 现有大语言模型在复杂医疗决策中的局限

近年来，大语言模型（LLMs）在医学领域的应用取得了显著进展，在医学执业资格考试和标准化问答任务中表现优异。然而，在面对MMD这类罕见且异质性高的复杂病例时，现有的单体LLM系统暴露出明显的局限性： 首先，**缺乏动态推理能力**。现有的医疗LLM评测多基于静态的单选题或孤立的病历摘要，难以模拟真实临床环境中“观察-决策-反馈”的动态临床路径。 其次，**幻觉与推理断裂**。在处理复杂的长尾医学知识（如MMD特定的Suzuki分期与侧支循环评估）时，通用模型容易产生幻觉或忽视关键的阴性体征。 最后，**单一视角的局限性**。真实的临床决策是多专家博弈与妥协的结果，单一模型难以通过自我反思来模拟这种复杂的社会认知过程，导致决策缺乏全面性和可解释性。

### 1.3 多智能体协同与临床路径模拟的契机

为了突破上述局限，基于大模型的多智能体（Multi-Agent）系统应运而生。研究表明，通过为不同智能体赋予特定的专家角色（如主刀医生、影像专家），并通过结构化的辩论与共识机制，可以显著提升复杂推理任务的准确性。此外，结合临床路径环境（Clinical Pathway Environment, CP-Env）的仿真技术，使得在虚拟环境中预演手术决策及其长期预后成为可能。本研究旨在结合MMD的临床特性，构建一个基于多智能体协同的动态决策支持系统，以解决罕见病诊疗中专家资源稀缺与决策不确定性的问题。

## 研究意义 (Research Significance)

### 2.1 科学价值：从“概率预测”向“可计算共识”的范式转变

本研究不仅是将LLM应用于特定疾病，更是在计算机科学层面探索了如何将人类专家的**群体决策机制（Consensus Mechanism）**转化为可计算的数学模型。 通过引入多智能体辩论与共识矩阵（Consensus Matrix）算法，本研究尝试量化不同专科Agent之间的观点分歧与趋同过程。这种方法突破了传统单体模型“黑盒式”输出的局限，提供了一种基于逻辑交互的透明推理路径。这对于解决AI在医疗高风险决策中的“可信度”问题具有重要的理论意义，证明了通过角色化博弈可以有效降低模型幻觉并提升推理的鲁棒性。

### 2.2 临床价值：针对罕见病的动态风险预演与决策优化

针对烟雾病这一罕见且高风险的病种，本研究提出的框架具有直接的临床应用潜力：
• **术前规划的“虚拟沙盘”**：通过模拟MDT讨论，系统能够综合文本病历与影像报告（如CTP血流参数），在术前识别出易被忽视的风险因素（如高灌注风险），辅助医生制定更安全的手术方案。
• **动态路径管理**：本研究超越了静态诊断，引入了时间维度的临床路径模拟。系统能够预演不同治疗手段（如保守治疗 vs. 手术）在术后不同时间点可能引发的并发症或认知功能变化，从而实现从“对症治疗”到“全周期预后管理”的跨越。

## 3. 方法学

### 3.1 数据收集与清洗 

本研究将构建一个专用于烟雾病临床决策的多模态文本数据集。我们纳入经数字减影血管造影（DSA）确诊为烟雾病的成年患者病例。为适应大语言模型（LLM）的输入特性，我们将多模态临床数据转化为结构化的文本描述：

• **临床文本数据**：提取患者的主诉、既往史（如高血压、卒中史）、神经功能评分（mRS, NIHSS）以及围术期记录。
• **影像报告文本化 (Imaging-to-Text)**：鉴于烟雾病分期对血管影像的高度依赖，我们不直接输入原始图像，而是利用最新的视觉语言模型（如 Claude 3.7 或 GPT-4V）结合放射科医师的审核，将DSA和CT灌注（CTP）图像转化为标准化的文本描述。重点提取**Suzuki分期**（I-VI期）的特征描述（如“颈内动脉末端狭窄”、“颅底异常血管网形成”） 以及脑血流动力学参数（如CBF、Tmax）的定量描述，因为这些参数对预测术后脑高灌注综合征（CHS）至关重要。

### 3.2 MDT智能体角色定义

为了模拟真实世界的多学科会诊（MDT），我们基于 **Moya-Agent** 框架构建了四个具有独立知识库和推理逻辑的专用智能体。各智能体通过提示工程（Prompt Engineering）被赋予特定的角色设想（Persona）和决策权重。

**1. 神经外科智能体 (Surgeon Agent - The "Operator")**
	• **核心任务**：评估手术指征与术式选择。
	• **知识库**：基于《烟雾病治疗中国专家共识》及Suzuki分期标准。
	• **决策逻辑**：重点关注供体血管（颞浅动脉）的条件和受体血管的匹配度。对于Suzuki III-IV期患者，倾向于推荐直接搭桥（Direct Bypass）或联合搭桥；对于血管条件极差的患者，则评估间接搭桥（Encephalo-duro-arterio-synangiosis, EDAS）的可行性。

**2. 神经放射科智能体 (Radiologist Agent - The "Eye")**
	• **核心任务**：提供客观的影像学证据支持，不仅是诊断，更是风险评估。
	• **知识库**：专注于血流动力学评估标准（ASPECTS评分、CTP参数）。
	• **决策逻辑**：通过分析CTP数据中的脑血流（CBF）和达峰时间（Tmax），识别“高灌注风险区”。如果术前CBF已经较高，该智能体会向外科智能体发出**“高灌注综合征（CHS）预警”**，建议调整手术策略或加强围术期血压管理。

**3. 神经内科/围术期管理智能体 (Neurologist Agent - The "Guardian")**
	• **核心任务**：评估卒中复发风险及围术期药物管理。
	• **知识库**：抗血小板药物使用指南、卒中二级预防指南。
	• **决策逻辑**：关注患者的TIA发作频率和既往梗死灶。在决策链中，负责权衡停用抗血小板药物带来的血栓风险与手术出血风险，并制定术后血压控制目标。

**4. 主持人/共识智能体 (Moderator Agent - The "Integrator")**
	• **核心任务**：汇总各方意见，计算共识度，生成最终决策。
	• **算法机制**：引入**共识矩阵（Consensus Matrix）**。该智能体不直接生成原始观点，而是解析上述三个智能体的输出，计算决策的一致性（利用 **Kendall’s W 系数**）。若一致性低于阈值（如 W<0.7），主持人将触发新一轮“辩论”，要求持有少数派意见的智能体提供更强的证据链（如引用具体文献）。
