## 🧠 项目核心理念
DynamicLLM是一个探索**人类可理解神经网络记忆机制**的前沿研究项目。我们的核心假设是：传统Transformer架构中的Feed-Forward Network (FFN) 可以被更加透明、可解释的知识存储机制Memory Bank所替代，从而构建出既强大又可理解的大语言模型。
## 🎯 研究目标
### 主要目标
- **构建可解释的LLM**: 用人类可理解的Memory Bank替代传统的黑盒FFN层
- **验证知识存储假设**: 探索是否可以通过显式知识库实现与FFN等效的记忆功能
- **推进可解释AI**: 为构建透明、可信的AI系统提供新的技术路径
### 研究意义
- 🔍 **透明性**: 让AI的"思考"过程变得可观察、可理解
- 🛡️ **可控性**: 通过显式知识管理提升模型的可控性和安全性
- 🧪 **科学价值**: 深化对神经网络记忆机制的理解
## 💡 核心研究思路
### 架构创新
我们提出了一种全新的Transformer变体：
- **传统架构**: `Attention → FFN → LayerNorm`
- **我们的架构**: `Attention → Searcher → Memory Bank → Attention输出与Memory Bank输出拼接 → LayerNorm`
### 知识存储机制
- **Memory Bank**: 包含大量三元组知识条目的显式知识库
- **动态检索**: 根据上下文动态检索相关知识进行推理
- **可解释性**: 每个推理步骤都可以追溯到具体的知识条目

## 🤔 核心研究问题
### 待解决的关键问题
1. **知识整合机制**: 如何让离散的知识条目产生连贯的语言输出？
2. **表示学习**: Memory Bank/KnowledgeDataset是否改变了模型的表示学习模式？
3. **记忆vs生成**: 显式记忆与隐式生成能力之间的平衡点在哪里？
### 研究假设
- **假设1**: 传统FFN本质上是一种隐式的知识存储机制
- **假设2**: 显式知识存储可以保持模型性能的同时提升可解释性
- **假设3**: 当前的文本生成问题源于知识检索策略而非架构本身

## ⚡ 当前技术挑战与解决方案

### 🚨 关键技术挑战

#### 挑战1：性能差距（-23.9%）
**现状**：记忆库架构性能明显低于baseline
**分析**：可能原因包括知识检索不够精准、知识整合机制不够优化
**解决方案**：
- 改进知识检索算法，提高相关性匹配
- 优化知识整合机制，减少信息丢失
- 探索动态权重分配策略

#### 挑战2：三元组提取精度不足（60% vs 70%目标）  
**现状**：卢泽宁的三元组提取需要提升
**解决方案**：
- 优化训练数据质量
- 调整模型架构参数
- 引入主动学习策略
