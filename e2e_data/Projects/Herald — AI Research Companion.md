# Herald — AI Research Companion

## 项目概览

**Herald** 是一个主动式科研 AI 伙伴系统，借鉴 OpenClaw/nanobot 架构，专为科研场景设计。

它不是被动的问答工具，也不是端到端自动化流水线。它是一个真正的研究伙伴——能主动思考、有记忆、会成长，与研究者进行深度协作。

### 核心理念

**人定方向，Herald 补位执行。**

不是替代研究者，而是一个越用越懂你的研究伙伴。主动发现文献盲区、帮你实现代码框架、帮你展开论文大纲。

- 参考项目代码：pci-3 `/home/pci/ycz/reference/`（nanobot + netclode 已 clone）

### 核心功能方向

1. **文献智能调研（主动补盲）** — 在你未察觉文献缺失时主动调研
2. **代码框架实现（人给框架，Herald 填充）** — 通过外部 Coding Agent 完成代码工作
3. **论文撰写辅助（大纲→完整论文）** — 渐进式展开，而非一次性生成
4. **与研究者深度交流、持续学习成长** — 持久记忆，知道你的研究风格和偏好

## 文档规范

### 写作风格

参考标杆：[[构建自托管的云端 Coding Agent — Netclode 技术解读]]

**核心原则**：
- **主体是叙事，代码只在必要时点缀，起"锚定"作用**
- **讲故事而非写规格**：每个决策记录"为什么这样选"，包括被否决的方案和理由
- **图表优先**：架构图（mermaid）、对比表 > 大段代码
- **通俗与精确并重**：先大白话讲概念，再用代码片段确认

### 更新机制

- 每次重大技术决策，新建一篇 Notes 记录推理过程，并在项目主页的索引中添加链接
- 每次实现里程碑，在项目主页的 Log 中记录
- 笔记允许迭代更新，但重大修改需要在文末标注更新日期和原因
- 实践中发现原方案有误，不删除原内容，而是用删除线标注并写明新结论（**保留决策演进轨迹**）

### 命名规范

- 所有 Herald 相关笔记统一前缀：`Herald — `
- 放在 `Notes/` 目录下
- 项目主页放在 `Projects/` 目录下
