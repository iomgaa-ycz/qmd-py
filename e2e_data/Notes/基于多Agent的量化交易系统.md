## 现状与问题
1. TradingAgents与QuantAgent的提出代表越来越多的研究者开始吧注意力转向基于Agent驱动的量化交易系统
2. 但是这这一类系统存在一个统一的问题就是计算效率非常低慢，并且其所有的收益成本并没有考虑token本身的成本。而这类模型为了追求效果的最佳往往会使用最SOTA的模型。
3. 最SOTA的闭源模型存在费用贵并且信息安全无法保证的问题。
4. 现在也有研究者开始尝试使用Agent来生成交易因子
5. 并且现在的所有研究都是在模拟盘进行的，没有经过实盘的考验。
6. 多Agent可能存在累计误差，导致同一个事件有不一样的决策输出，不具有确定性

## 我们的贡献点
1. 我们设计了一种基于多Agent系统-因子交易所结合的混合交易方式

## 思路
1. 多Agent系统负责
	1. 生成、管理、修改、删除因子
	2. 生成一天内的交易计划
		1. 判断方向与结构
		2. 生成风险与执行约束
2. 执行层（PandaAI）
	1. 输入
		1. 当前价格、流动性
		2. 第一层的结构化计划
		3. 当前仓位、风险敞口
	2. 输出
		1. 精确仓位
		2. 下单路径
		3. 时间分布
	
|因子类型|示例|数据来源|常见更新频率|说明|
|---|---|---|---|---|
|技术因子|MA、RSI、MACD|价格|**日 / 分钟**|高频噪声大，半衰期短|
|动量因子|3M / 6M / 12M return|价格|**周 / 月**|中期最稳定|
|价值因子|PE、PB、E/P|财报 + 价格|**月 / 季**|变化慢，需滞后|
|质量因子|ROE、利润率|财报|**季 / 年**|极慢，重稳定|
|波动率因子|IV、历史波动|价格 / 期权|**日 / 周**|风控核心|
