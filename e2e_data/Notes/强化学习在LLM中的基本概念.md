# 强化学习在LLM中的基本概念

强化学习在大语言模型中的应用本质上是将传统RL概念映射到文本生成任务中，核心问题是"当前序列好不好？基于当前序列后续生成某一个token好不好？"

## 核心组件映射

强化学习在LLM中使用时，需要将传统RL概念重新定义：

- **Policy $\pi_\theta$ (策略网络)**: 被训练的主要LLM，输入文本，输出文本
- **Reward Model $R_\phi$ (奖励模型)**: 提前训练好的LLM，输入完整文本，输出一个价值（数字）
- **Critic $V_\gamma$ (价值模型)**: 被训练的另一个LLM，输入部分文本，预测一个价值（数字）
- **States $s_t$ (状态)**: $t$ 时刻得到的序列
- **Action $a_t$ (动作)**: $t$ 时刻LLM输出的Token

## 工作原理

LLM中强化学习RL就是把评估文本质量这件事用数学和公式量化了，变得可执行了。好的内容就加以鼓励，不好的内容就给予抑制。

这种映射使得我们可以将成熟的强化学习算法（如PPO、GRPO）直接应用到语言模型的训练中，实现基于人类反馈的模型优化。

- **量化评估**: 将主观的文本质量判断转化为客观的数值评分
- **序列优化**: 针对每个token生成进行实时优化
- **反馈学习**: 通过奖励信号引导模型学习人类偏好
