## 📦 1. 全局安装 Node.js / npm

推荐使用 NodeSource 源进行标准安装，确保 `node` 和 `npm` 二进制文件位于标准系统路径 `/usr/bin` 下。

### 1.1 执行安装脚本 (Root)

Bash

```
# 添加 NodeSource 源 (Node.js 20.x LTS)
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -

# 安装 Node.js (包含 npm)
apt-get install -y nodejs
```

### 1.2 验证基础安装

Bash

```
node -v
npm -v
```

此时安装路径通常为 `/usr/bin/node` 和 `/usr/bin/npm`，默认对所有用户可见。

## 🛡️ 2. 修复 npm 全局权限 (强烈推荐)

默认情况下，`npm install -g` 需要 root 权限，这在多用户/集群环境下极不安全且不便。以下配置将全局包路径重定向至系统级公共目录。

### 2.1 修改 npm 默认路径

Bash

```
# 创建公共全局目录
mkdir -p /usr/local/npm-global

# 配置 npm 使用该目录作为前缀
npm config set prefix=/usr/local/npm-global
```

### 2.2 调整目录权限

确保所有用户对该目录有读取和执行权限，但维持 root 所有权结构：

Bash

```
chown -R root:root /usr/local/npm-global
chmod -R 755 /usr/local/npm-global
```

### 2.3 配置环境变量 (对所有用户生效)

通过 `/etc/profile.d` 注入路径，无需修改每个用户的 `.bashrc`。

Bash

```
echo 'export PATH=/usr/local/npm-global/bin:$PATH' > /etc/profile.d/npm-global.sh
chmod +x /etc/profile.d/npm-global.sh
```

🔴 **注意**：配置完成后，用户需 **重新登录** 或执行 `source /etc/profile` 才能生效。

## 🥟 3. 全局安装 Bun (Root + 多用户可用)

官方脚本默认安装在 `$HOME/.bun`，导致其他用户无法使用。我们需要手动将其移动至系统级目录。

### 3.1 下载并解压 (临时位置)

Bash

```
# 不要加任何参数，先安装到 root 目录
curl -fsSL https://bun.sh/install | bash
```

此时文件位于 `/root/.bun/bin/bun`。

### 3.2 部署到系统路径

将二进制文件移动到 `/usr/local/bin`，这是所有用户的默认 `$PATH` 路径。

Bash

```
# 移动二进制文件
mv /root/.bun/bin/bun /usr/local/bin/bun

# 授予执行权限
chmod 755 /usr/local/bin/bun
```

### 3.3 清理临时文件 (可选)

清理 root 目录下的残留文件，保持环境整洁。

Bash

```
rm -rf /root/.bun
```

## ✅ 4. 最终验证

建议切换到一个**普通用户**账号进行以下测试，确保环境配置无误。

### 4.1 验证命令可用性

Bash

```
# 检查路径 (应返回 /usr/bin/node)
which node 

# 检查路径 (应返回 /usr/local/bin/bun)
which bun

# 检查版本
bun --version
```

### 4.2 验证 npm 全局安装 (无需 sudo)

尝试安装一个全局工具（例如 `yarn` 或 `pm2`），验证是否不再需要 sudo：

Bash

```
npm install -g yarn
yarn --version
```

如果安装成功且未报错 `EACCES`，说明第 2 步权限配置成功。
