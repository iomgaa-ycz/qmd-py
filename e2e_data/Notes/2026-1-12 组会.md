### 中台构建
本学期初，我们提出并明确了中台建设的整体思路，如下图所示：
![[CleanShot 2026-01-11 at 10.42.09@2x.png]]
截至目前，在基础模型层面，我们已初步构建起**自部署模型与外部模型相结合的混合调用模式**（自训练模型仍在规划中）。  
其中，自部署模型累计生成 Token 数量已超过 **1.4B**，外部模型累计调用量超过 **0.69B**。
![[56fe68b712cfd18fb15d73b5a0e66904.png]]
#### 自部署模型
在自部署模型方面，我们搭建了一套**以 GPUStack 为核心、以自有 RTX 4090 显卡为计算节点**的模型部署体系，并计划后续长期固定 **1–2 张显卡**用于模型服务部署。
GPUStack 支持对话模型、图像生成模型、语音模型、嵌入模型、重排模型等多种模型的一键式部署，并通过统一的标准接口向用户提供服务，显著降低了模型部署与调用的复杂度。
![[CleanShot 2026-01-11 at 10.54.35@2x.png]]
#### 外部模型
在外部模型方面，我们采用了**API 调用与包月套餐相结合**的使用模式。
具体而言，我们将 MiniMax、阿里百炼、月之暗面等多个平台的模型 API 统一接入至自部署的 One API 平台，实现了模型的集中调度与统一管理。这一方式有效降低了 API Key 泄漏带来的风险，同时也避免了每位学生单独调用、频繁报销所造成的管理成本。
![[CleanShot 2026-01-11 at 10.59.19@2x.png]]
![[CleanShot 2026-01-11 at 10.59.39@2x.png]]
鉴于基于 API 的模型调用成本相对较高，我们还额外采购了两个高等级包月套餐，专门供需要频繁调用高性能模型的成员使用，以进一步优化整体成本结构与使用体验。
## 科研部分
### ExplicitLM-lora
基于原始的 ExplicitLM 论文工作，我们在实践中发现从零开始训练完整模型的难度较高。因此，当前研究方向调整为构建一种**类似 LoRA 的轻量化结构**，以向现有模型中注入外部知识。  
目前已完成整体模型架构的设计与实现，正在开展系统性的消融实验，计划在春节前完成全部实验，并同步完成论文初稿的撰写。

### SwarmEvo
我们提出构建一种**将群体智能与进化算法相结合的 Agent 系统（SwarmEvo）**，以应对传统 Agent 系统在复杂代码问题场景下表现受限的问题。
为验证所提出方法的有效性与可行性，我们计划以 **MLE-Bench** 作为基准数据集进行评测。
目前，系统整体架构已搭建完成，正在分别对**基于群体智能的 Agent 系统**与**基于进化算法的 Agent 系统**进行独立测试与对比分析。后续将进一步开展融合模型的综合实验。  
我们计划于 **3 月前完成全部实验**，并于 **3 月中旬前完成论文初稿的撰写**。
