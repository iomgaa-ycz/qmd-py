ServBay是一个为开发者设计的本地Web开发环境管理工具，它把所有Web开发需要的工具都集成在一个图形化界面中，实现一键安装和管理。

## 核心概念

### 什么是ServBay？
用最简单的话说：ServBay就像是开发者的"瑞士军刀"，把各种编程语言、数据库、Web服务器等开发工具都装在一个应用里，打开就能用，不需要复杂的配置。

### 为什么需要ServBay？
传统方式下，开发者需要：
- 分别安装PHP、Python、Node.js等语言环境
- 配置MySQL、PostgreSQL等数据库
- 设置NGINX、Apache等Web服务器
- 处理各种版本冲突和依赖问题

ServBay解决了这些痛点：一次安装，全部搞定。

## 主要功能特性

### 支持的编程语言
- **PHP**：5.6 - 8.5 版本
- **Python**：2.7, 3.5 - 3.14 版本
- **Node.js**：12 - 23 版本
- **其他**：Golang、Java、.NET、Ruby、Rust

### 支持的数据库
- **MySQL**：5.1 - 9.1 版本
- **MariaDB**：10.4 - 11.5 版本
- **PostgreSQL**：10 - 16 版本
- **NoSQL**：MongoDB、Redis

### Web服务器
- Caddy
- NGINX
- Apache

### 集成工具
- phpMyAdmin（数据库管理）
- Adminer（轻量级数据库管理）
- Composer（PHP依赖管理）
- Ollama（运行大语言模型）

## 独特优势

### 1. 无系统侵入
不会修改系统配置，不会污染系统环境，卸载后不留痕迹。

### 2. 多版本并存
可以同时运行多个PHP版本、多个数据库实例，互不干扰。

### 3. 快速安装
3分钟完成全部安装，相比Docker更轻量级。

### 4. 高级功能
- 自定义域名和顶级域名（TLD）
- 内置SSL证书生成
- 邮件服务器集成
- 私有CA和PKI系统
- 反向代理和隧道支持
